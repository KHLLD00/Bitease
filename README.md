# Pasta Nirvana Website

V1 static restaurant website based on the BiteEase architecture reference, rebuilt for Pasta Nirvana.

## Stack
HTML, CSS, vanilla JavaScript, JSON menu data, localStorage cart, WhatsApp checkout.

## Menu
The supplied Pasta Nirvana 2026 menu is stored in data/menu-data.json.

## Before production
Confirm final domain, physical address, opening hours, delivery fees/areas, payment details and provide approved food photography/logo assets.
